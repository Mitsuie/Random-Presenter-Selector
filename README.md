# 演習投影 統合管理システム

大学の演習授業などで、課題の投影（発表）を行う学生をランダムに指名し、その実施状況（出席・欠席）を記録・管理するための統合GUIアプリケーションです。

名簿の準備・変換（Excel → CSV）から、授業中の学生指名・出席記録までを**ひとつのアプリケーション画面からシームレスに操作**できます。

---

## 主な特徴

- **統合GUIエントリーポイント (`main.py`)**:
  - 最上部のモード切替ボタン（`[🎯 学生指名 | 📋 名簿変換]`）で、必要な機能をワンクリックで切り替え可能。
  - プロジェクター投影時にも邪魔にならない、コンパクトでシンプルな画面設計（サイドバーなし）。
- **シームレスな機能連携**:
  - 名簿変換画面でExcelをCSVに変換後、「🎯 この名簿で学生指名を開始する」ボタンを押すだけで、自動的に指名画面に対象CSVがセットされた状態で移行できます。
- **視認性と操作性に優れた指名UI**:
  - 教室の後方や投影スクリーンからでもハッキリ確認できる大フォント表示。
  - 「出席 (○)」「欠席 (×)」のワンクリック即時保存。
  - 名簿の進行状況（全人数、未投影人数、実施済人数）が一目でわかるステータスバッジ。
- **外観モード切替**:
  - 教室の照明やプロジェクターの視認性に合わせて、ヘッダー右上のボタンからワンクリックで「Light / Dark」モードを切り替え可能。

---

## 必要な環境と事前準備

### Pythonスクリプトから実行する場合
Python 3.10以上がインストールされた環境で、以下のコマンドを実行して依存ライブラリをインストールしてください。

```bash
pip install -r requirements.txt
```
（主要ライブラリ: `customtkinter`, `openpyxl`, `pyinstaller`）

### 実行ファイル（`.exe`）を利用する場合
Pythonやライブラリの事前インストールは不要です。`dist/` 配下の実行ファイルを起動するだけで動作します。

---

## 使い方

アプリケーションは以下のコマンド、または実行ファイル（`.exe`）から起動します。

```bash
python main.py
```

### 1. 名簿の準備と変換（事前準備）
ヘッダーの **「📋 名簿変換」** を選択します。
1. **[Step 1]** 「📂 参照...」ボタンを押し、大学の教務システム等からダウンロードしたExcel名簿（`.xlsx` 等）を選択します。
   - ※Excelファイル内に「学籍番号」「学生氏名」「学生氏名＿カナ」の3列が含まれている必要があります。
2. **[Step 2]** 出力先CSVのファイルパスを確認・指定します（Step 1のファイル名から自動提案されます）。
3. **「⚡ 変換を実行する」** ボタンをクリックします。
4. 変換が成功すると完了メッセージが表示されます。
   - 続けて指名を行う場合は、表示された **「🎯 この名簿で学生指名を開始する」** ボタンを押すと、そのまま学生指名画面へ移動します。

### 2. 学生の指名と記録（授業本番）
ヘッダーの **「🎯 学生指名」** を選択します。
1. **名簿CSVの読み込み**:
   - 名簿変換から引き継いだ場合は既に読み込まれています。
   - 既存のCSVを利用する場合は、「📂 CSVファイルを選択」ボタンから対象のCSVを選択してください。
   - ステータス欄に現在の進行状況（全人数、未投影、実施済）が表示されます。
2. **抽選の実行**:
   - **「🎲 抽選開始」** ボタンをクリックすると、未投影（「投影実施可否」が空欄）の学生からランダムに1名が選出されます。
   - 学籍番号、氏名、カナが大きく表示されます。
3. **出席・実施の記録**:
   - **「出席 (○)」** または **「欠席 (×)」** ボタンを押すと、結果がCSVファイルに即座に上書き保存され、待機画面に戻ります。
   - 記録を行わずに戻りたい場合は **「記入なし（戻る）」** を押してください。

## プロジェクト構成

```
演習投影学生指名プログラム/
│
├── main.py                  # アプリケーションのエントリーポイント
├── requirements.txt         # 依存パッケージ定義
├── main.spec                # 単一EXEビルド設定
│
├── core/                    # 業務ロジック層（GUI非依存）
│   ├── roster_converter.py  # Excelから必須列抽出＆CSV変換
│   └── lottery_manager.py   # CSV読み込み・集計・抽選・結果保存
│
├── ui/                      # プレゼンテーション層（CustomTkinter）
│   ├── main_window.py       # メインウィンドウ（ヘッダー・モード管理）
│   ├── selector_view.py     # 学生指名画面（待機・抽選結果）
│   └── converter_view.py    # 名簿変換画面（ステップ入力・連携）
│
└── example_files/           # サンプルデータ
    ├── example.xlsx         # サンプルExcel名簿
    └── example.csv          # サンプル変換後CSV
```

---

## 実行ファイルのビルド（配布用exeの作成）

以下のコマンドを実行することで、単一の実行ファイル（`.exe`）を生成できます。

```bash
pyinstaller --clean main.spec
```
ビルドが完了すると、`dist/演習投影統合管理システム.exe` に実行ファイルが生成されます。
